> 原文：[How Anthropic's cybersecurity team built a threat detection platform with Claude Code](https://claude.com/resources/articles/how-anthropic-uses-claude-cybersecurity)；原作者：Jackie Bow；原文发表：2026-05-12

在 Jackie Bow 的整个职业生涯中，她一直在构想这样一种理想的安全工具：它能够无缝调取那些真正决定生死的上下文信息——不仅是枯燥的底层日志与孤立告警，还包括 Slack 中的日常对话、内部架构文档，以及判断某次异常究竟是真实入侵还是虚惊一场的关键业务背景——而这一切，根本不需要人类分析师耗费大量精力去手动翻阅排查。

加入 Anthropic 后，她终于获得了实现这一梦想的舞台——而 Claude 成为了与她并肩作战的核心协作者。Jackie 负责执掌 Anthropic 的检测平台工程团队（Detection Platform Engineering），专注于防御性网络安全：识别潜在威胁并对可能发生的入侵快速响应，而非传统的渗透找茬。这支团队的日常职责包括对全系统进行可疑行为全天候监控、对安全告警进行快速分诊过滤，并在异常演变为严重事故之前将隐患扼杀在萌芽状态。

对于一家致力于打造具备前沿超强能力大模型的 AI 企业而言，这项防御工作是不可逾越的生命线。[Anthropic 的《负责任扩展政策》（Responsible Scaling Policy）](https://www.anthropic.com/news/anthropics-responsible-scaling-policy) 将每次前沿模型的发布节奏与安全承诺直接挂钩，这意味着 Jackie 团队的工作直接裁定着公司究竟能安全发布哪些产品。

“我由衷地觉得，现在迎来了安全工程师的黄金时代，”作为 Anthropic 检测平台工程技术主管的 Jackie 感慨道，“我终于能亲手造出那些我梦寐以求多年的得力工具了。”

## 核心痛点：溺亡在无休止的日志与告警汪洋中

凡是带领过安全运营团队的负责人，都对这种疲于奔命的窘境刻骨铭心。

刺耳的警报突然拉响。一位一线安全分析师打开终端，开始了熟悉的“痛苦循环”：在五六个完全割裂的独立安全工具之间反复横跳，每个工具都有一套专有的查询语法和复杂的心智模型。分析师必须在大脑中强行记忆各个平台的特性，并在不同的操控界面与查询语句之间进行高频的精神消耗型上下文切换。

每一次威胁调查，最终都沦为一场枯燥乏味的“数据考古发掘”——在互不连通的孤立系统间艰难拼凑零散的碎片线索。对于绝大多数企业团队而言，一次再简单不过的异常排查都要耗费数小时，而一旦遭遇复杂的疑难事件，排查周期更会拖长至数天。

“一个人每天所能仔细审核的告警数量是存在生理极限的，超过一定阈值后，他们审查的细致程度必然会出现断崖式下跌，”Jackie 剖析道。

她的团队下定决心彻底终结这种被动局面。他们直面内心发问：究竟是什么在不断榨干我们的心力？哪些环节充斥着低价值的机械重复？到底是什么在阻碍我们去攻坚更具战略影响力的核心工作？

答案浮出水面：告警分诊在分析师能够确认威胁真实性之前，就已吞噬了大把黄金时间；横跨割裂系统的手动关联分析拖慢了一切响应；而在各种专有语法和 UI 之间的高频摩擦，全天候累加成了极其沉重的认知负荷。

随着 Anthropic 业务版图的高速扩张，攻击面在成倍扩大，对安全防线的严苛考验更是与日俱增。

“如果不借助类似 Claude 这样的智能体进行能力倍增，我们根本无法跟上 Anthropic 自身的扩张步伐，”Jackie 直言。

## 解决方案：CLUE 平台（Claude 调查取证系统）

在短短数月内，Jackie 的团队打造出了 **CLUE（Claude Looks Up Evidence）**——一个彻底重塑安全团队威胁取证模式的现代化检测与响应平台。CLUE 并没有在原本就已繁冗的技术栈上再硬塞一个杂乱的仪表盘，而是提供了一个由 Claude 驱动的**自然语言对话接口**，通过原生的“工具调用（Tool Use）”机制直接穿透连接至 Anthropic 内部各大业务与底层系统。

使用 Claude Code 协助构建 CLUE，使传统的软件研发周期被成倍压缩，让团队得以在从容应对日常高压安全工作的同时，敏捷完成这一平台的研发。Jackie 团队仅用了一天时间就跑通了端到端概念验证（PoC），详尽的设计文档、分步开发与工程落地在一周内便全线交付。

“我们搭建这个系统的绝大部分过程，其实就是我和团队在跟 Claude Code 进行深度对话，”Jackie 回忆道，“它既是我们的架构设计搭档，更是我们的全栈结对开发者。”

彻底打破她固有认知的一刻，发生在一次她要求 Claude Code 为 CLUE 界面新增一个前端交互按钮时。她原本以为接下来不可避免要陷入 JavaScript 框架调优和繁琐 CSS 样式的泥潭，但 Claude Code 几乎瞬间交付了该功能，且实现品质比她自己动手写的还要优雅。

“那一刻我瞬间顿悟：我再也不会被自身的前端技术短板所束缚了。只要我能构想出来的系统，我就能亲手造出来，”她说。

### 1. CLUE Triage：告警智能预先分诊

在海量警报涌入的第一时间，**CLUE Triage 会在人类分析师接触到它们之前，先一步完成全自动的首轮初筛分诊**。Claude 通过预置的工具链，从 Anthropic 内部各大系统中为每条警报极速补充丰富的上下文——包括调取关联的 Slack 对话记录、内部设计文档、代码仓库提交记录以及数仓行为日志。随后，它会自动为警报归类定性：是误报（False Positive）、真正例（True Positive）、恶意攻击，还是符合预期的正常运维行为；并为每条警报打上清晰的置信度评分，使分析师能瞬间洞悉轻重缓急，将注意力集中在真正的关键隐患上。

这一步富化上下文的操作，解决了每一位安全专家心知肚明的顽疾：警报到达时永远只是孤立的散点。一次偶发的密码输错、一次略显反常的 API 调用、或者一项配置变更——脱离了具体语境，这些散点完全就是垃圾噪音。唯有注入了完备的内部上下文（这位操作员工是谁？他们手头当时在推进什么项目？这次操作是否符合该业务团队的历史行为范式？），真实的危险信号才会清晰显现。

“内部业务上下文，正是让警报真正与你的具体系统环境产生关联所不可或缺的灵魂拼图，”Jackie 解释道。

### 2. CLUE Investigate：自然语言全天候威胁取证

借助 CLUE，安全分析师如今可以用最自然的母语对所有高危安全日志发起深度检索。想查清楚“过去 24 小时内这套系统所有发生过的登录失败记录”？只需向 CLUE 随口发问，Claude 就会在后台全自动编写并执行精准的底层 SQL 查询。

“在编写精细、毫无破绽的复杂查询语句方面，Claude 的表现远比人类工程师靠谱得多，”Jackie 评价道。该工具运行着一套严密的智能体循环（Agentic Loop）：由一个中央编排智能体（Orchestrator）向多个专业子智能体并发下发检索指令，并行执行跨源查询，采集证据，并最终自动汇编成一份条理清晰的综合取证长报告。以往需要耗费数小时人工逐条拼接关联的重体力活，如今在短短 **3 到 4 分钟**内即可全自动出炉。

量化指标充分印证了这种效能提升：在平均单次调查会话中，CLUE 会自主发起 **25 次工具调用**以及近 **11 次复杂多表查询**——这远远超出了一位人类分析师在合理时间内所能手动执行的极限，而且准确度更高。更重要的是，如果换作人工操作，上述每一次工具调用都意味着要在浏览器里单独打开一个不同的运维控制台，或者经历一次心智消耗极大的操作界面切换。

然而，真正的核心壁垒依旧在于“内部业务上下文”。CLUE 依托强大的工具链直连 Anthropic 内部生态，赋予了 Claude 调阅企业专有组织知识的特权——这是任何第三方商业安全平台无论如何都不可能企及的。当警报拉响时，Claude 会主动潜入 Slack 查验该团队近期是否公开讨论过系统计划性割接维护；它会主动向数仓发起比对，调阅受影响组件的历史常态基线；它甚至会直接通读代码仓库中的源码，搞清楚该服务在底层逻辑上究竟是在干什么。

### 3. 数据治理与权限合规审查实战

团队以一个极具代表性的日常数据治理场景展示了 CLUE 的实战威力：核查三名外包承包商在过去两个月内，是否越权访问了任何不该接触的敏感文档。

Jackie 指出，这类涉及跨部门审计的调查，以往至少需要耗费资深安全分析师大半天的密集人工翻查——需要反复查询访问审计日志、逐一交叉比对 IAM 权限矩阵，并核验相关文档的数据密级归属。而在 CLUE 中，Claude 读懂自然语言指令后，自主拟定清晰的排查策略，生成逻辑严密的查询代码，彻底将底层的繁复技术细节抽象隐藏。**整个排查在短短几分钟内彻底完成**，不仅输出了详尽的结论摘要与防御加固建议，而且对整个调查过程中运行的每一条 SQL 给予了 100% 透明的可审计呈现。

## 成效量化：用硬核数据说话

在着手搭建 CLUE 之初，团队就立下规矩：绝不满足于“感觉上好像变快了”的模糊主观感受，必须拿出扎实的量化数据来验证成果。

- **误报率断崖式暴跌**：在 CLUE Triage 上线之前，系统触发的每三条告警中就有一条属于毫无意义的误报（~33%）。而经过智能体预先富化上下文与初步分诊后，**误报率骤降到了仅剩 7%**，这意味着人类分析师能将宝贵的时间全力聚焦于真正致命的威胁信号上。
- **防御视野前所未有地拓宽**：相比单纯的提速，更深远的改变在于团队所能覆盖的防御盲区。在以前，海量低置信度的异常信号由于精力有限只能被迫放弃审查；而现在，CLUE Triage 实现了对每一条流入告警的 100% 上下文富化排查，强大的批处理能力将以往在仪表盘上被视作背景白噪音的数千条微弱信号全部纳入了审查视野。
- **规模化节省海量研发工时**：在系统实际投产的 30 天统计周期内，CLUE 累计自动化执行了约 12,000 次深层查询与 27,000 次工具调用——这相当于人工手动操作所需耗费的 **1,870 小时（折合 234 个全职人天）**。相比传统的人工排查，实现了 **5 到 10 倍的时间效率飞跃**。
- **持续进化的质检验收体系**：准确性的科学度量往往比单纯统计速度更具挑战。团队持续严谨抽检 CLUE 的分诊裁决，追踪人机判定分歧，并正在打磨严密的反馈闭环，以探究 Claude 是否捕捉到了人类可能忽略的隐秘蛛丝马迹，反之亦然。每一次调查留下的全流程会话转录文本提供了决定性的支持：任何一次排查都能被完整复盘，清楚溯源 Claude 究竟调阅了哪些数据、以及它是如何一步步推理得出最终结论的。

## 架构哲学与演进方向：放手让 Claude 像大模型那样去调查

在人工智能学术界，有一个著名的哲学论断被奉为圭臬——**“苦涩的教训（The Bitter Lesson）”**：计算机科学家 Rich Sutton 指出，长期来看，试图将人类专有经验与思维逻辑硬编码到模型系统中的做法，其表现永远落后于赋予模型通用的计算能力与广泛自主探索空间。Jackie 与团队一直在深入反思这一法则对现代安全检测与响应的深远启示。

“在 CLUE 研发的早期阶段，团队内部曾激烈争论过究竟应当在多大程度上限制 Claude 的调查推演路径，”Jackie 回忆道，“源自传统 SOAR（安全编排、自动化与响应）时代的工程直觉不断告诫我们：必须写死固定 Playbook 剧本、严格规定每一步的先后顺序、力求将整个排查流程做成绝对确定性的齿轮。但我们在实操中敏锐地捕捉到了一种奇妙的现象：**当我们给予 Claude 自由探索的弹性——只给它必要的工具权限和最终目标，而不是生搬硬套死板的步骤——它往往会走出令人拍案叫绝的敏锐排查路径，完全跳出了我们原有的思维定势。它常常能沿着那些人类从未预设过的路径，揪出原本会被彻底遗漏的关键致命上下文。**”

真正的安全智慧，在于**为模型划定清晰的合规防线（可以调用哪些工具、能够访问哪些敏感数据源），但在具体攻防策略上给予大模型充分的自主裁量权**。这一顿悟正深刻指导着 CLUE 下一步的演进方向：

1. **从“被动响应”迈向“主动搜猎（Threat Hunting）”**：目前的 CLUE 主要响应既有告警。但其底层架构已具备承载更宏大野心的能力：持续自主探索。智能体不再静待告警规则被动触发，而是可以在系统内不知疲倦地主动搜寻蛛丝马迹——捕捉那些尚未被人类编写出明确规则的未知异常，嗅探那些孤立看完全合法、但在全局宏观聚类下极度反常的蛛丝马迹。
2. **依托自身实战不断自我进化**：团队完整归档了每一次调查的全部转录轨迹。这些实战语料正在凝聚成一个庞大的组织经验知识库，Claude 可以自主向其检索学习过去真实攻防调查的演进规律。假以时日，CLUE 将生长出任何人类个体分析师都无法独立维系的庞大“集体安全记忆”。
3. **拥抱非确定性（Embracing Non-determinism）**：传统安全软件向来将“输出不一致”视为严重 Bug，而 CLUE 反其道而行之，将其视为核心优势（Feature）。面对同一条告警，智能体在不同时间可能会采取截然不同的全新探索路径，而这恰恰极具价值——第二条路径往往能挖出第一条路径错失的暗礁。团队目前正在积极探索多条调查策略并发并行的模式，通过多路结果的交叉比对印证，将威胁溯源的全面性推向极致。

“安全运营领域的‘苦涩教训’是什么？”Jackie 总结道，“过去数十年，我们耗费了无数心血去构建那些试图将人类思考方式机械硬编码的安全系统。**而新一代的安全武器，应当是将探索取证的强大能力完整赋予先进模型，放手让它们去开辟出超越人类既定条条框框的更卓越解法。**”
